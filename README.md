This is a designated repository for the community protection of ITNs project.

TITLE: EFFECTS OF ISECTICIDE-TREATED NETS ON MALARIA PREVALENCE AMONGST USERS AND NON-USERS: A MODELLING STUDY

Simulations were run using the OpenMalaria simulation model. The simulation files are stored in the 01_Simulation_files folder.
The simulated OpenMalaria data are stored in the 02_Simulation_Data folder.
The R scripts for analysis and producing all the manuscript figures can be located in the 03_Results folder
All figures are saved in the 04_Figures folder

Analysis are reproducible after cloning this repository. The R project contains all scripts. 
The simulated data are loaded in the Figure2_prevalence_reduction.R script and once loaded in the R environment, figures 3 and 4 can be reproduced as well
